# Architecture Decision Records

Cherry 프로젝트의 설계 과정에서 내린 기술적 의사결정 기록입니다.

## 의사결정 프로세스

- **코드베이스 분석**: Claude (백엔드/프론트엔드 구조 탐색)
- **리서치/사례 조사**: ChatGPT (당근마켓/번개장터 사례, 업계 관행, 비용 분석)
- **비용 분석**: Claude + 사용자 (AWS 인프라 비용, 리소스 비교)
- **최종 결정**: 팀 논의를 통해 트레이드오프를 비교하고 확정

## 핵심 설계 원칙

1. **관심사 분리**: 거래 상태(status)와 존재 여부(deleted_at)를 분리
2. **단순함 우선**: 현재 서비스 규모에 맞는 적절한 복잡도
3. **실무 감각**: 당근마켓 등 실서비스 관행을 참고하되 과투자 방지
4. **비용 의식**: 모든 결정에서 개발 공수와 운영 비용을 정량 비교
5. **기존 인프라 활용**: 이미 구축된 인프라를 최대한 활용하여 추가 비용 방지
